strip_newline(char *s)

Removes trailing \n and \r from the end of a line so strings compare cleanly (e.g., "EXIT" vs "EXIT\n").

reap_background_children(void)

Uses waitpid(-1, ..., WNOHANG) in a loop to collect any finished background children (prevents zombie processes) without blocking the shell.

read_line_cb(CircularBuffer *cb, int fd, char *out, size_t out_cap)

Reads bytes from fd using read(), stores them in the circular buffer, and returns the next complete line (delimited by \n). Handles EOF by returning leftover bytes as the final line.

exec_child_or_die(char **argv)

Runs in a child process: calls execvp(argv[0], argv) to execute the command. If exec fails, prints an error and exits the child with failure (_exit(1)).

run_single(char *cmdline, int wait_for_child)

Splits one command line into argv, forks, runs the command in the child, and either waits (SINGLE) or does not wait (CONCURRENT) in the parent.

run_piped(char *cmd1, char *cmd2)

Implements cmd1 | cmd2: creates a pipe, forks two children, redirects stdout of the first into the pipe and stdin of the second from the pipe using dup2, closes unused pipe ends, then waits for both.

main(void)

Initializes the circular buffer, loops reading a mode line and corresponding command line(s), dispatches to run_single / run_piped, reaps background children each iteration, exits on EXIT or EOF, and frees resources.
